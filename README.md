# Projeto de Extensão PIBIEX — Formação em Desenvolvimento de Jogos

Repositório destinado ao controle, versionamento e organização da documentação, materiais didáticos, estudos e projetos desenvolvidos no âmbito do projeto de extensão PIBIEX.

## 🎯 Propósito

O projeto tem como proposta investigar e desenvolver estratégias de **formação técnica em desenvolvimento de jogos**, utilizando a ferramenta **GameMaker** como recurso para aprendizagem prática de programação, desenvolvimento de jogos e criação de projetos digitais.

A iniciativa está relacionada aos princípios de **inclusão digital, formação tecnológica e inovação social**, buscando proporcionar aos participantes uma experiência prática de desenvolvimento e criação de produtos digitais.

## 📚 Objetivos em desenvolvimento

Entre as possibilidades a serem investigadas pelo projeto estão:

* desenvolver conhecimentos básicos de programação;
* introduzir conceitos de desenvolvimento de jogos;
* utilizar o GameMaker como ferramenta de aprendizagem;
* estimular a criatividade e a resolução de problemas;
* desenvolver projetos práticos de jogos;
* promover o contato com ferramentas e processos utilizados no desenvolvimento de software;
* investigar estratégias de ensino de tecnologia para diferentes públicos;
* avaliar a evolução técnica dos participantes durante as atividades.

> Os objetivos, metodologia e estratégias de formação serão refinados ao longo da execução do projeto.

## 🗂️ Organização

```text
docs/       → documentação e planejamento do projeto
materiais/  → materiais didáticos, aulas e exercícios
gamemaker/  → estudos e projetos desenvolvidos no GameMaker
evidencias/ → registros e resultados das atividades
```

## 🕹️ GameMaker

Os estudos e projetos relacionados ao GameMaker serão organizados de forma progressiva, contemplando conceitos fundamentais da ferramenta, experimentações e projetos práticos.

A organização dos estudos poderá evoluir conforme as necessidades identificadas durante as atividades do projeto.

## 📈 Evolução do projeto

Este repositório também funciona como instrumento de acompanhamento da evolução do projeto, permitindo registrar:

* decisões metodológicas;
* alterações no planejamento;
* materiais produzidos;
* atividades realizadas;
* projetos desenvolvidos;
* resultados obtidos;
* dificuldades encontradas;
* aprendizados e melhorias propostas.

## 🎓 Contexto acadêmico

Projeto vinculado ao programa PIBIEX da instituição de ensino, com finalidade de extensão e formação tecnológica.
